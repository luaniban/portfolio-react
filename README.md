# Portfólio

Código do meu portfólio: [portfolio.luanibanhez.tech](https://portfolio.luanibanhez.tech).

## O que tem

- Cena de montanha com tema de dia e de noite.
- Mascote que acompanha a rolagem da página.
- Placas de seção e os 8 projetos com miniatura, descrição e link.
- Versão em português e em inglês.
- Currículo em PDF.

## Tecnologias

- Next.js 16, React 19 e TypeScript
- Tailwind CSS 4
- sharp, para as imagens

## Como rodar

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000`. Os testes rodam com `npm test`.
